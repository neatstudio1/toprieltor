# ТЗ для Claude Design · Лендинг A «Подбор новостройки»

## 1. Задача

Сделай дизайн посадочной страницы для рекламы в Яндекс Директе. Страница одна, цель у неё одна: человек проходит короткий квиз и оставляет телефон, чтобы получить подборку квартир.

- **Компания:** TOPиелтор (ysrealty.ru), агентство по новостройкам Екатеринбурга. Сооснователь и лицо бренда — Яна Чекулова, риелтор по новостройкам с 2019 года и сертифицированный дизайнер интерьеров.
- **Главное отличие от конкурентов:** ведём покупку под ключ, от подбора до ремонта и сдачи в аренду. Застройщики, Циан и банки заканчивают на сделке.
- **Кто приходит:** люди из поиска Яндекса по запросам «купить квартиру в новостройке», «купить новостройку», «купить новую квартиру», «подбор новостроек», «услуги риелтора». В основном семьи и покупатели в ипотеку.
- **Трафик:** 70–90% с телефонов. **Сначала проектируй мобильную версию**, потом десктоп.
- **Адрес:** `ysrealty.ru/lp/podbor`. Заголовок объявления совпадает с H1 страницы.

## 2. Что сдать

1. **Мобильная версия, 390 px**, вся страница сверху вниз. Это основной макет.
2. **Десктоп, 1440 px**, вся страница.
3. **Квиз — оверлей поверх страницы**, отдельными артбордами для мобильного и десктопа:
   вопросы 1–4 → экран результата → контакты → «спасибо».
4. **Плавающая панель внизу экрана** на мобильном.
5. Состояния: кнопка (обычная, наведение, нажатие), выбранный ответ квиза, поле телефона (пустое, заполненное, ошибка), раскрытый вопрос FAQ.

## 3. Визуальный стиль

Используй визуальный язык сайта ysrealty.ru:

| Токен | Значение |
|---|---|
| Фон светлых секций | `#ffffff` и `#f6f6f8` через одну |
| Тёмный фон (первый экран и финал) | `#09090b`, текст `#fafafa` |
| Основной текст | `#18181b`, второстепенный `#71717a` |
| Акцент (кнопки, выбранные ответы) | `#4f46e5`, светлый акцент `#eef2ff` |
| Линии | `#e4e4e7` |
| Шрифт | Inter: заголовки 800, текст 400–500 |
| Надзаголовки | JetBrains Mono, капслок, разрядка 0,14em — как «ЭКОСИСТЕМА ПОКУПКИ НОВОСТРОЙКИ ПОД КЛЮЧ» на сайте |

- **Много воздуха.** Отступ между секциями 104 px на десктопе и 56 px на мобильном. Короткие тексты, крупные заголовки.
- **Карточки:** скругление 22 px, без теней, фон на тон отличается от секции.
- **Кнопки:** высота 56 px, скругление 14 px. На мобильном главная кнопка во всю ширину.
- **Фото только настоящие.** Никаких стоковых людей и иконок-иллюстраций. Иконки — простые линейные, в акцентном цвете.

### 2. Боль

### 7. Частые вопросы
H2: **Частые вопросы**. Аккордеон, по умолчанию всё свёрнуто.

1. **Почему для меня бесплатно?** — Нам платит застройщик из своего маркетингового бюджета. Цена квартиры такая же, как в офисе продаж.
2. **Я уже был у застройщика. Можно подключить вас?** — Напишите, проверим. У каждого застройщика свои правила закрепления клиента, иногда подключиться ещё можно.
3. **Через вас не выйдет дороже?** — Нет. Цена застройщика, а у партнёров бывают условия, которых нет на сайте.
4. **Помогаете с ипотекой?** — Да. Подаём заявку в несколько банков и берём лучшее одобрение.
5. **Ремонт тоже делаете?** — Да. Дизайн-проект, бригада и материалы со скидкой у партнёров. Можно взять только проект или только приёмку.
6. **Можно купить, если я в другом городе?** — Да. Видеопросмотры, электронная подпись и регистрация без поездок.

## 5. Квиз — оверлей

- Ответы — крупные кнопки во всю ширину. Нажатие сразу ведёт к следующему вопросу, отдельной кнопки «Далее» нет. Справа в кнопке может быть серая подпись.

**Экран результата** (до контактов — это важно):

## 6. Нельзя

- Меню навигации и ссылки, уводящие со страницы.
- Стоковые фото людей, домов и «счастливых семей».
- Слайдеры и автоматические карусели.
- Видео на первом экране.
- Длинные абзацы: в блоке не больше двух строк текста на элемент.
- Отдельная секция с квизом на странице: квиз только оверлеем.
